Why install the Chrome extension?

Without the extension, an Oversite capture from a webpage carries the screenshot region and the OCR text — Oversite can read what's on screen, but not where it came from. With the extension installed, every capture from Chrome, Brave, Edge, Arc, or any Chromium-based browser also includes the page URL, the surrounding DOM context, and the source link of any highlighted text. The extension is what turns a screenshot into an AI-legible reference.

The extension is bundled with Oversite, not distributed through the Chrome Web Store. Two reasons: it keeps the install local — no Google review cycle in the loop — and the codesigned bytes the wizard reveals are the same bytes that get loaded, with no rotation in between. The in-app wizard walks you through enabling Developer Mode and loading the unpacked extension. Two minutes, one time.
